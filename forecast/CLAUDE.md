# CLAUDE.md — โครงงานพยากรณ์สารหนูในแม่น้ำข้ามพรมแดน

ไฟล์นี้สรุปงานที่ทำมาก่อนในแชต Claude (claude.ai) เพื่อให้ Claude Code ทำต่อได้ทันที

## โครงงานคืออะไร
"แบบจำลองคณิตศาสตร์สำหรับพยากรณ์การแพร่กระจายของสารหนูในแม่น้ำข้ามพรมแดนของประเทศไทย จากข้อมูลเฝ้าระวังของภาครัฐ"
(A Mathematical Model for Forecasting the Spread of Arsenic in Thailand's Transboundary Rivers from Government Surveillance Data)
ผู้จัดทำเป็นนักเรียน อยู่ อ.เชียงคาน จ.เลย (จุดตรวจที่ใกล้บ้านที่สุด E9-NK08 แก่งคุดคู้)

## กฎที่ต้องทำตาม
- ตอบเป็นภาษาไทยทางการ อ่านเป็นธรรมชาติ
- ใช้ข้อมูลทางการเท่านั้น (คพ., สคพ.1, สคพ.9) ข่าวใช้เป็นบริบท ไม่ป้อนแบบจำลอง
- ห้ามแต่งตัวเลข ค่าที่ไม่รู้ให้เขียน `[ต้องกำหนด]`
- ค่าพยากรณ์ต้องติดป้ายว่า "ค่าพยากรณ์ ไม่ใช่ค่าตรวจวัด" เสมอ (`is_measured=false`)
- ค่า "<0.010" เป็นข้อมูลถูกตัด (left-censored) ห้ามแทนด้วยค่าคงที่
- เป็นการเฝ้าระวังเท่านั้น ไม่ใช่การวินิจฉัยทางการแพทย์

## โครงสร้าง
```
config/parameters.json      ค่าคงที่ของแบบจำลอง (λ=2, ช่วงอ้างอิง 14 วัน, มาตรฐาน 0.01)
data/raw*/                  ตารางจากรายงาน คพ. ทุกรอบ
data/processed/             ชุดข้อมูลที่ใช้ (water_arsenic_long.csv, model_table.csv, stations.csv ...)
data/forecast/              ผลพยากรณ์ + ผลทดสอบย้อนหลัง
scripts/run_all.py          รันทุกขั้นตามลำดับ
scripts/03_forecast_baseline.py   แบบจำลอง A (Tobit) + แบบจำลองหลัก censored log-AR(1)
scripts/06_export_site.py   เขียน JSON ให้เว็บใน ../web/data/
../web/index.html             เว็บ static ไฟล์เดียว (ไม่มี build) อ่าน ../web/README.md
results/                    รูปกราฟ
```

## คำสั่ง
```
pip install -r requirements.txt
python scripts/run_all.py            # คำนวณใหม่ทั้งหมด แล้วเขียน ../web/data/*.json
cd ../web && python -m http.server 8000   # เปิดเว็บที่ http://localhost:8000
```
เปิด `index.html` ตรง ๆ (file://) ไม่ได้ เพราะเว็บ fetch ไฟล์ใน `../web/data/`

## แบบจำลอง (ต้องตรงกับบทที่ 2 ของเล่ม)
- y = ln C, d = Δวัน/14
- μ = a_j + ρ^d (ŷ_prev − a_j), s = σ√(1−ρ^(2d)) ถ้าค่าก่อนหน้าถูกตัด ŷ = ค่าคาดหมาย truncated normal (วน EM 6 รอบ)
- likelihood แบบ Tobit (วัดได้ / ต่ำกว่าขีด / เป็นช่วง) ลงโทษ λΣ(a_j − m_g)² + 0.01Σ(m_g − ln0.01)²
- ผลพยากรณ์: P50 = e^μ, P10/P90 = e^(μ ∓ 1.2816·k·s), p เกิน = 1 − Φ((ln0.01 − μ)/(k·s))
- ค่าปัจจุบัน: ρ = 0.468/14 วัน, σ = 0.510, k = 1.136, β (แบบจำลอง A) = 0.297 (CI 0.249–0.345, n=623)
- ทดสอบย้อนหลัง rolling origin: RMSE 0.56 vs persistence 0.68 (236 คู่), Brier 0.174 vs 0.248 (512)
  แยกเครือข่าย: กก–โขง ชนะชัด, สาละวิน ใกล้เคียง persistence, โขงอีสานข้อมูลไม่พอ (Brier แย่กว่า climatology)
