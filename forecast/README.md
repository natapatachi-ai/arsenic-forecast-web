# ชุดข้อมูลพยากรณ์สารหนู แม่น้ำกก–สาย–รวก–โขง

ชุดข้อมูลนี้พร้อมใช้กับโค้ดและพร้อมพยากรณ์ ข้อมูลทั้งหมดมาจากรายงานของกรมควบคุมมลพิษ (คพ.) และข่าวที่อ้างผลของ คพ. ไม่มีการเก็บตัวอย่างภาคสนาม และไม่มีค่าที่สร้างขึ้นเอง ค่าใดที่ยังไม่มีแหล่งยืนยันระบุเป็น `[ต้องกำหนด]`

## วิธีใช้ (VS Code + Python 3.10 ขึ้นไป)
```bash
pip install -r requirements.txt
python scripts/run_all.py --force      # build -> QC gate -> forecast
```
ผลพยากรณ์อยู่ที่ `data/forecast/forecast_latest.json` ซึ่งเว็บสามารถอ่านได้โดยตรง

## โครงสร้าง
```

docs/sources/         ข้อความที่ถอดจาก PDF ต้นฉบับ (ใช้ตรวจย้อนกลับ)

config/parameters.json  ค่ามาตรฐาน, pKa, E°, Kd, RfD/CSF พร้อมแหล่งอ้างอิง
scripts/01..07, run_all.py, pcd_pdf_tables.py
.github/workflows/update-forecast.yml   ระบบอัปเดตอัตโนมัติ (GitHub Actions)

```

ค่าจากข่าวที่ใช้ก่อนหน้านี้ย้ายไปไว้ที่ `data/raw_tables/superseded/` แล้ว ผลเทียบข่าวกับตาราง คพ. อยู่ที่ `data/processed/news_vs_official_water.csv` ซึ่งตรงกัน 100 จาก 106 ค่า ค่าที่ไม่ตรงคลาดสูงสุด 10 เท่า เช่น ข่าวลง RU01 รอบ 22 เป็น 0.17 แต่ตาราง คพ. เป็น 0.017

ความขุ่นรอบ 3–4 ของแม่น้ำโขงในรายงานรอบ 24 อยู่ที่ NK01–NK02 แต่ในรายงาน ก.ย. 2568 อยู่ที่ NK02–NK03 ซึ่งตรงกับจุดที่มีค่าสารหนู ชุดข้อมูลจึงใช้ฉบับ ก.ย. 2568

การแก้ไขค่าระหว่างฉบับรายงาน บันทึกไว้ใน `data/processed/revisions_sediment.csv` เช่น สารหนูในตะกอน KK05 รอบ 12: ฉบับรอบ 12 ระบุ 29 แต่ฉบับรอบ 13 แก้เป็น 11 ชุดข้อมูลใช้ค่าฉบับล่าสุด

ตั้งแต่ พ.ย. 2568 คพ. ปรับความถี่เป็นเก็บน้ำเดือนละ 1 ครั้ง และเก็บตะกอนทุก 2 เดือน แบบจำลองรองรับช่วงห่างไม่เท่ากันอยู่แล้ว ส่วนสถานี KK03, KK04, KK06, KK08, KK13, KK14 และ SU01 เลิกเก็บในปี 2569 ผลพยากรณ์ของสถานีเหล่านี้จึงเป็นการคาดการณ์ระยะไกลที่มีความน่าเชื่อถือต่ำ

## แบบจำลองพื้นฐานที่ใช้ได้ทันที (03_forecast_baseline.py)
- **แบบจำลอง B (พยากรณ์):** log-AR(1) ที่รองรับข้อมูลเซ็นเซอร์ (Tobit/ช่วงค่า) สำหรับช่วงเวลาไม่สม่ำเสมอ และใช้ partial pooling ตามกลุ่มลำน้ำ ให้ผลเป็น P10/P50/P90 และ P(C > 0.01) โดยปรับความกว้างช่วงด้วยผลทดสอบย้อนหลัง
- **แบบจำลอง A (อธิบาย):** Tobit ของ ln C กับ ln(ความขุ่น) ใช้รอบ 1–24 ได้ β = 0.37 (CI95 0.32–0.43) ซึ่งสอดคล้องกับสมมติฐานว่าสารหนูเกาะอนุภาคแขวนลอย (Kd·TSS)
- **ทดสอบย้อนหลังแบบ rolling origin (ตั้งแต่รอบ 6, 187 ค่า):** RMSE(ln) 0.52 เทียบกับ persistence 0.67, Brier 0.190 เทียบกับ climatology 0.245, coverage ของช่วง 80% ก่อนปรับเท่ากับ 0.73 จึงต้องปรับขยายด้วย k = 1.13

ข้อมูลน้ำทั้งหมดเป็นระดับ A แล้ว ถ้ามีรอบใหม่ที่ยังมีเพียงข่าว ให้ใส่ใน `data/raw_tables/water_as_news_*.csv` ระบบจะใช้ค่านั้นชั่วคราว และแทนด้วยตาราง คพ. เมื่อได้มา

## เพิ่มข้อมูลรอบใหม่
1. เพิ่มแถวใน `data/raw_tables/water_as_news_R11-R23.csv` หรือสร้างไฟล์ตารางกว้างแบบเดียวกับ `water_as_R01-R10_pcd.csv`
2. ใส่วันที่ของรอบใน `data/processed/rounds.csv`
3. รัน `python scripts/run_all.py` ระบบจะคำนวณใหม่เฉพาะเมื่อ hash ของข้อมูลดิบเปลี่ยน และจะไม่อัปเดตผลถ้า QC ไม่ผ่าน

> ผลพยากรณ์ไม่ใช่ค่าตรวจวัด ใช้เพื่อเฝ้าระวังเท่านั้น ไม่ใช่การวินิจฉัยทางการแพทย์ ควรยืนยันกับ คพ. กรมควบคุมโรค และการประปาในพื้นที่

## ระบบอัปเดตอัตโนมัติ (ใกล้เวลาจริง)
1. `05_watch_pcd.py` ตรวจหน้ารายการเอกสารของ สสภ.1 ทุก 6 ชั่วโมงผ่าน GitHub Actions
2. ถ้าพบรายงาน "ครั้งที่" ใหม่ จะดาวน์โหลด PDF แล้วถอดตารางภาคผนวก ข ด้วย `pcd_pdf_tables.py` (ทดสอบกับรายงานตะกอนรอบ 12 และ 13 แล้ว ตรงกับค่าที่ตรวจทานด้วยมือทั้ง 6,300 ค่า)
3. QC gate: ค่ารอบเก่าในฉบับใหม่ต้องตรงกับข้อมูลเดิมอย่างน้อย 98% และรอบใหม่ต้องมีค่าอย่างน้อย 10 จุด ถ้าไม่ผ่าน จะไม่เขียนทับข้อมูล
4. `run_all.py` คำนวณใหม่ แล้ว `06_export_site.py` ส่งออกไฟล์ให้หน้าเว็บ จากนั้น GitHub Pages เผยแพร่ภายในไม่กี่นาที
5. ถ้าเว็บต้นทางบล็อกเครื่องของ GitHub ให้ดาวน์โหลด PDF เอง แล้วรัน `python scripts/05_watch_pcd.py --pdf ไฟล์.pdf --kind water --round 25 --dates "..."`

ข้อจำกัด: คพ. เก็บน้ำเดือนละครั้ง ค่าตรวจวัดใหม่จึงมาเป็นรายเดือน ระหว่างรอบ ระบบจะใช้ข้อมูลรายชั่วโมงหรือรายวัน (ระดับน้ำ ฝน) มาปรับค่าประมาณได้ เมื่อเชื่อม `04_fetch_hydrology.py` แล้ว
