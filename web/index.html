ดูพื้นที่ของฉันแผนที่ค่าจริงแผนที่พยากรณ์เปรียบเทียบ

พื้นที่ของฉันเลือกจังหวัด อำเภอ และตำบลที่คุณอยู่ ระบบจะบอกว่าแม่น้ำใกล้บ้านมีสารหนูเท่าไร คาดว่าจะเป็นอย่างไร และควรทำอย่างไร

ครอบคลุมทุกจังหวัดและอำเภอทั่วประเทศ ตำบลมีให้เลือกใน 13 จังหวัดที่มีพื้นที่ห่างจากแม่น้ำที่ตรวจพบสารหนูไม่เกิน 30 กิโลเมตร จังหวัดอื่นไม่ได้รับน้ำจากแม่น้ำเหล่านี้ จึงแสดงผลระดับอำเภอ

    หรือเลือกทีละขั้น

    ● ค่าตรวจวัดจริง

    แผนที่ค่าจริงผลตรวจของกรมควบคุมมลพิษและสำนักงานสิ่งแวดล้อมฯ เท่านั้น ไม่มีค่าพยากรณ์ปน

    เลื่อนแถบเวลาเพื่อดูแต่ละวันเก็บตัวอย่าง ลากเพื่อเลื่อนแผนที่ ใช้ปุ่ม + − หรือ Ctrl + ลูกกลิ้งเพื่อซูม (มือถือใช้สองนิ้ว) วางเมาส์บนแม่น้ำหรือจุดตรวจเพื่อดูชื่อ ค่าจริง และค่าพยากรณ์ของตำแหน่งนั้น

    ตารางค่าจริง:
    ค่าตรวจวัดล่าสุดของทุกจุด (มก./ล.)
    จุดตรวจแม่น้ำพื้นที่ค่าจริงล่าสุดวันเก็บตัวอย่างประวัติค่าจริงเกินมาตรฐาน
    ◆ ค่าพยากรณ์ล่วงหน้า (ไม่ใช่ค่าตรวจวัด)

    แผนที่พยากรณ์พยากรณ์ล่วงหน้า 1–3 รอบของแต่ละเครือข่าย สีคือค่ากลาง P50 พื้นที่สีแดงคือโอกาสเกินมาตรฐานตั้งแต่ 50%

    พยากรณ์ช่วงไหน: วันที่ตรวจล่าสุดและวันเป้าหมายของแต่ละรอบ (นับจากวันประมวลผล )
    เครือข่ายตรวจล่าสุด (ค่าจริง)ระยะห่างปกติรอบหน้า2 รอบข้างหน้า3 รอบข้างหน้า

    วันเป้าหมาย = วันตรวจล่าสุดของเครือข่าย + ระยะห่างปกติระหว่างรอบ × h ค่าเฉลี่ยใน log คือ a + ρd(ln Cล่าสุด − a) โดย d = จำนวนวัน ÷ 14 และ ρ = ยิ่งไกล ค่ายิ่งเข้าหาค่าเฉลี่ยของจุดตรวจและช่วงยิ่งกว้าง วันเป้าหมายที่ผ่านไปแล้วแปลว่าหน่วยงานยังไม่เผยแพร่รายงานรอบนั้น ค่าพยากรณ์ยังใช้ได้จนกว่าจะมีค่าจริงมาแทน

    ตารางพยากรณ์:
    ค่าพยากรณ์ P50 (ช่วง P10–P90) และโอกาสเกิน 0.01 มก./ล.
    จุดตรวจพื้นที่รอบถัดไป (ยังไม่มีรายงาน)2 รอบข้างหน้า3 รอบข้างหน้า

    การทดสอบย้อนหลังทำกับ "รอบหน้า" เท่านั้น ค่าพยากรณ์ 2–3 รอบข้างหน้ามีช่วงกว้างขึ้นและยังไม่ได้ทดสอบย้อนหลัง ช่องที่ทำเครื่องหมาย * มีระยะพยากรณ์เกิน 120 วัน จึงมีความน่าเชื่อถือต่ำ และแผนที่จะไม่ใช้ค่านั้นระบายสีแม่น้ำ

    ค่าจริง | ค่าพยากรณ์

    แผนที่เปรียบเทียบฝั่งซ้ายคือค่าที่ตรวจวัดได้จริงในวันนั้น ฝั่งขวาคือค่าที่แบบจำลองพยากรณ์ไว้ก่อนวันนั้น โดยใช้ข้อมูลก่อนวันเก็บตัวอย่างเท่านั้น

    ลากปุ่มกลมตรงกลางไปซ้ายหรือขวาเพื่อเทียบสองฝั่ง เลือกวันเก็บตัวอย่างจากแถบเวลา ตารางใต้แผนที่เปลี่ยนตามวันที่เลือก

    จุดตรวจพื้นที่ค่าจริงพยากรณ์ไว้ P50ช่วง P10–P90ผลความแม่นยำทุกครั้งของจุดนี้

    กราฟรายจุด: ค่าจริงเทียบค่าพยากรณ์ทุกครั้ง

    เส้นทึบสีเข้ม = ค่าจริง เส้นประสีน้ำเงิน = ค่าพยากรณ์ล่วงหน้า 1 รอบ แถบฟ้า = ช่วง P10–P90 เพชรสีน้ำเงิน = พยากรณ์รอบหน้า

    ค่าตรวจวัดจริง ต่ำกว่าขีดตรวจวัด ค่าพยากรณ์ P50 และ P10–P90 พยากรณ์รอบหน้า มาตรฐาน 0.01
    วันเก็บตัวอย่างค่าจริงพยากรณ์ P50ช่วง P10–P90ผลการเทียบ

    ทุกจุด ทุกครั้ง

    แกนนอน = ค่าพยากรณ์ P50 แกนตั้ง = ค่าจริง (เฉพาะค่าที่ตรวจวัดได้) เส้นทแยงคือพยากรณ์ตรงพอดี

    จังหวัดที่ได้รับผลกระทบเรียงตามทิศน้ำ แยกสถานะจากค่าจริงล่าสุดกับค่าพยากรณ์รอบหน้า

    ตัวเลขสุขภาพมาจากกรมควบคุมโรค (ปีงบประมาณ 2569) ข้อมูลในบรรทัดที่มีแหล่งข่าวกำกับเป็นบริบท ไม่ได้ใช้ในการคำนวณ

    แม่น้ำไหลไปไหนบ้างเส้นทางน้ำจากต้นทางถึงทะเล และค่าจริงล่าสุดของจุดตรวจบนเส้นทาง

    แม่น้ำกก สาย และรวก ไหลลงแม่น้ำโขงที่อำเภอเชียงแสน แม่น้ำโขงไหลเข้า สปป.ลาว แล้วกลับมาเป็นพรมแดนไทย–ลาวตั้งแต่จังหวัดเลยถึงอุบลราชธานี ก่อนไหลต่อไปกัมพูชาและเวียดนาม ส่วนแม่น้ำสาละวินไหลจากเมียนมาผ่านชายแดนแม่ฮ่องสอนกลับเข้าเมียนมาไปทะเลอันดามัน

    มีการบำบัดหรือยัง และได้ผลอย่างไรมาตรการของหน่วยงาน สถานะล่าสุด และผลที่หน่วยงานรายงาน

    การบำบัดที่ทำอยู่จริงคือการบำบัดน้ำประปาที่โรงผลิตน้ำ ส่วนการบำบัดในแม่น้ำ เช่น ฝายดักตะกอน ยังไม่มีการก่อสร้าง แม่น้ำจึงยังมีสารหนูเกินมาตรฐานตามผลตรวจล่าสุด ผลการบำบัดน้ำประปาเป็นผลที่หน่วยงานแถลง ยังไม่พบตารางผลตรวจน้ำประปารายจุดที่เผยแพร่

    คำนวณอย่างไร และอัปเดตอย่างไรคณิตศาสตร์ประยุกต์กับเคมีของสารหนู

    ใช้ข้อมูลทางการทั้งหมด ไม่มีการเก็บตัวอย่างเอง ระบบตรวจหารายงานใหม่ของ สคพ.1 และ สคพ.9 ทุก 6 ชั่วโมง ถ้าพบรายงานใหม่จะถอดตาราง ตรวจคุณภาพข้อมูล คำนวณใหม่ และเผยแพร่หน้าเว็บอัตโนมัติ ถ้าข้อมูลไม่ผ่านการตรวจจะไม่เผยแพร่

    ln Ct | ln Ct−1 ~ N( as + ρd(ln Ct−1 − as), σ²(1 − ρ2d) ), d = Δt / 14 วัน
    พยากรณ์ h รอบข้างหน้า: E[ln Ct+h] = as + ρdh(ln Ct − as), Var = σ²(1 − ρ2dh) (ยิ่งไกล ยิ่งเข้าใกล้ค่าเฉลี่ยระยะยาวของจุดนั้น และช่วงกว้างขึ้น)
    ค่า "<0.010" และ "≤0.010" ใช้ likelihood แบบ Tobit: P(ln C ≤ ln 0.010) = Φ((ln 0.010 − μ)/σ)
    สารหนูที่เกาะอนุภาค: fp = Kd·TSS / (1 + Kd·TSS) → ln C = a + β·ln(ความขุ่น), β = –

    ลดความเสี่ยงได้อย่างไรข้อมูลเพื่อการเฝ้าระวัง ไม่ใช่การวินิจฉัยทางการแพทย์

    คำแนะนำทั่วไปตามที่หน่วยงานสาธารณสุขเผยแพร่ ถ้ามีอาการผิดปกติควรพบแพทย์

    เลือกแหล่งน้ำ

    ไม่ดื่มหรือใช้น้ำจากแม่น้ำโดยตรง ใช้น้ำประปาหรือน้ำที่ผ่านการตรวจแล้ว การต้มน้ำไม่ได้กำจัดสารหนู หน่วยงานในหนองคายแนะนำเครื่องกรองแบบ RO สำหรับน้ำดื่ม

    กลุ่มที่ควรระวังเป็นพิเศษ

    ผู้ทำประมงและผู้ใช้น้ำในลำน้ำเป็นประจำ เด็กเล็ก หญิงตั้งครรภ์ ผู้สูงอายุ ไม่ควรใช้น้ำแม่น้ำชงนมหรือประกอบอาหาร

    อาหารจากลำน้ำ

    เนื้อปลาบริโภคได้ แต่ควรเลี่ยงพุง เครื่องใน และไส้ปลา งดใช้น้ำแม่น้ำรดผักในช่วงที่ผลตรวจเกินมาตรฐาน และติดตามผลตรวจผักและปลาของจังหวัด
