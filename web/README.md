# เว็บไซต์ "สารหนูไหลไปทางไหน" (web/)

เว็บแบบ static ไม่ต้อง build เปิดด้วย Live Server ใน VS Code หรือ `python -m http.server` ในโฟลเดอร์นี้ (เปิดไฟล์ตรง ๆ แบบ file:// จะโหลดข้อมูลไม่ได้)

## ไฟล์
| ไฟล์ | ที่มา |
|---|---|
| index.html | หน้าเว็บทั้งหมด (HTML + CSS + JavaScript ไม่มี library ภายนอก ยกเว้นฟอนต์ Google) |
| data/forecast_latest.json, observations.json, history.json, meta.json | สร้างโดย `../forecast/scripts/06_export_site.py` ทุกครั้งที่คำนวณใหม่ |
| data/geo.json | สร้างครั้งเดียวโดย `geo_src/build_geo.py` จากขอบเขตจังหวัด/อำเภอ (geoBoundaries) และแนวแม่น้ำ (OpenStreetMap) |

## สิ่งที่หน้าเว็บทำ
- แผนที่วาดเองบน canvas: ขอบเขต 77 จังหวัด, อำเภอในพื้นที่ศึกษา, แม่น้ำกก ฝาง สาย รวก โขง
- อนุภาคไหลตามทิศน้ำจริงแบบแผนที่ลม/พายุ สีและความกว้างของแถบตามความเข้มข้นสารหนูที่ประมาณระหว่างจุดตรวจ (log-linear interpolation ตามตำแหน่งบนแม่น้ำ) ช่วงที่ไม่มีจุดตรวจเป็นสีเทา
- แถบเวลา: รอบ 1–24 (ค่าตรวจวัด) และช่องสุดท้ายเป็นค่าพยากรณ์ ปุ่มเล่นย้อนดูการเปลี่ยนแปลงทุกรอบ
- พื้นที่สีแดง: อำเภอที่มีจุดตรวจของกรมควบคุมมลพิษรายงานสารหนูเกิน 0.01 มก./ล. ในรอบที่เลือก สีส้ม = เกินใน 3 รอบก่อนหน้า
  ในโหมดพยากรณ์ สีแดง = โอกาสเกิน ≥ 50%, สีส้ม ≥ 25%
- การ์ดตัวเลขแบบเรืองแสง (แนวทางเดียวกับ Peak Chart) และเมนูแก้วเหลว (แนวทางเดียวกับ Nimbus Liquid Navbar) เขียนใหม่เป็น JavaScript ล้วน ไม่ต้องใช้ React

## ข้อจำกัด
- พื้นที่สีแดงคำนวณจากผลตรวจของ คพ. ยังไม่ใช่ประกาศเขตพื้นที่อย่างเป็นทางการ ถ้ามีประกาศรายตำบล/อำเภอจากหน่วยงาน ให้เพิ่มเป็นชั้นข้อมูลแยกพร้อมเลขที่ประกาศและวันที่
- ค่าบนแม่น้ำระหว่างจุดตรวจเป็นการประมาณเพื่อแสดงทิศทาง ไม่ใช่ค่าตรวจวัด
- ต้นแม่น้ำกกและรวกฝั่งเมียนมา และแม่น้ำโขงเหนือสามเหลี่ยมทองคำ ไม่มีจุดตรวจในชุดข้อมูลนี้

## ใช้กับ React/shadcn ภายหลัง
ถ้าต้องการย้ายไป Next.js + Tailwind + shadcn ให้วาง `liquid-glass-navbar.tsx` และ `peak-chart.tsx` ใน `components/ui/` แล้วส่ง prop จาก JSON ชุดเดียวกัน (เช่น `PeakChart data={ค่ารายรอบ} value={ค่าล่าสุด}`)

## พื้นที่ของฉัน (เพิ่ม 24 พ.ย. 2569)
- `data/locations.json` สร้างจาก `geo_src/locations.txt` (รายชื่อกรมการปกครองผ่าน kongvut/thai-province-data: 77 จังหวัด 930 อำเภอ; ตำบลครบใน 13 จังหวัดที่อยู่ห่างแม่น้ำที่ตรวจพบไม่เกิน 30 กม.)
- แต่ละตำบลมี `d` ระยะเส้นตรงถึงแม่น้ำที่มีจุดตรวจ (กม.), `r` แม่น้ำ, `s` จุดตรวจที่ใกล้ที่สุด
- ระดับ: เกินมาตรฐาน (ห่าง ≤15 กม. และจุดตรวจเกิน) / เฝ้าระวัง / ติดตามข่าว / ไม่อยู่ในเส้นทางน้ำที่ตรวจพบ
- เพิ่มข้อมูลรายพื้นที่ได้ที่ `../forecast/data/context/affected_areas.json` ช่อง `local` (tambon, amphoe, what, source, url) แล้วรัน `../forecast/scripts/06_export_site.py`
- ฟอนต์ Sarabun (Google Fonts) ถ้าเครื่องมี TH Sarabun New จะใช้เป็นตัวสำรอง
